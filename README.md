# Student Result Visualization System

**Developed by:** Om Wade

## Project Description
The Student Result Visualization System is a Python-based data analysis project. It analyzes student marks and presents the results using charts and graphs.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Calculate total marks and percentage.
- Identify student pass or fail status.
- Assign grades based on performance.
- Analyze subject-wise average marks.
- Visualize student performance using charts.
- Export analyzed results to a CSV file.

## Project Files
- `student_result.py` – Main Python program
- `student_results.csv` – Student marks dataset
- `student_result_analysis.csv` – Analyzed results
- `student_performance.png` – Student performance chart
- `subject_average.png` – Subject average chart
- `grade_distribution.png` – Grade distribution chart

## How to Run
1. Install Python on your computer.
2. Install the required libraries:
   `pip install numpy pandas matplotlib`
3. Run the program:
   `python student_result.py`

## Conclusion
This project helps analyze student results and understand academic performance through data visualization.
